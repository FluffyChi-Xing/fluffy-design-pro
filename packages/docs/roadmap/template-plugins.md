# 路线图：独立前端模板插件

::: warning 规划中 — 尚未实现
当前 CLI 不提供模板插件安装命令，也没有可用的插件 registry、插件包名或兼容性协议。本文描述的是未来方向，不是当前使用说明。
:::

## 为什么规划这项能力

Fluffy Design Pro 当前以核心模板为中心。下一步计划支持独立发布的前端模板，让团队可以在不等待 CLI 核心版本发布的情况下，复用特定业务场景的页面、布局或能力组合。

理想方向包括：

- 由独立维护者发布可复用的前端模板包；
- 通过脚手架选择并安装适合项目的模板；
- 将模板能力与核心模板、CLI 版本和 Vue/Vite 版本建立明确兼容关系；
- 让模板拥有清晰的文档、示例、测试与升级边界。

## 需要先解决的问题

在正式开放前，需要定义：

1. **发布与发现**：插件包的命名空间、registry、版本发布和撤回策略；
2. **兼容性**：CLI、核心模板、Vue、Vite 与插件之间的版本矩阵；
3. **安装安全**：来源校验、依赖审阅、脚本执行边界和失败回滚；
4. **文件所有权**：插件生成的文件如何记录在 manifest 中，如何区分用户代码与插件代码；
5. **迁移机制**：插件升级时的变更计划、冲突提示、备份和回滚；
6. **质量标准**：模板的类型检查、构建、测试和无障碍验证要求。

## 当前不提供

- 没有公开的模板插件 registry；
- 没有已经发布的插件包或安装 API；
- 没有可复制执行的插件安装命令；
- 没有承诺的插件兼容版本、稳定性等级或发布时间。

在该能力发布前，请使用当前 CLI 提供的 core 模板、生成后的页面和组件基础。路线图会随着设计和实现进展更新。
